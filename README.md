# KwachaTrack 🇰🇼
**Trace the Kwacha. Track the Progress. Transform the Future.**

KwachaTrack is an open-source platform bridging the gap between Zambian government spending and citizens. We provide a real-time ledger for project budgets, AI-driven audits, crowdsourced field reporting, and open data exports to ensure public accountability.

---

### 🚀 Key Features
* **National Dashboard:** Real-time visibility into project budgets, expenditures, and completion status.
* **AI Transparency Audits:** Automated tools to flag fiscal irregularities by comparing spending against national benchmarks.
* **Crowdsourced Reporting:** Empowering citizens to submit incident reports with photographic evidence.
* **Open Data:** Full CSV export functionality for data journalists and civil society researchers.

### 🛠 Tech Stack
* **Backend:** Python (Flask) & SQLAlchemy
* **Frontend:** Tailwind CSS (Responsive/Mobile-First)
* **Database:** SQLite/PostgreSQL
